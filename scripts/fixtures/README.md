# Regression inputs

These files exercise parsers, compilers and evidence validators. They do not establish current platform or official-tool conformance.

`conformance-npm-support-capture.json.gz` is an anonymized input for the pure npm-support verifier. Its content-addressed objects retain checked SHA-256 and byte lengths after replacing producer home paths with `/home/developer`. Public provenance explicitly disables original assertion execution and official status promotion. Original capture bytes remain in the private archive. The tests retain positive closure checks and reject forged, incomplete or substituted inputs.

The inert [reviewed producer fixtures](reviewed-producers/README.md) have the same boundary. Third-party source inputs retain their original license files; no archived executable is loaded as a replacement for the current runtime.
